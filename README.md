# Typecraft — Timed Typing Practice Web Application

**Typecraft** is a modern, interactive web-based typing practice application designed to help users improve their typing speed, accuracy, and consistency. Users can either upload their own learning material—such as PDFs, images, or text files—or paste custom text directly into the application for personalized typing practice.

The application also provides a **Quick Practice** mode that automatically generates random typing passages based on different difficulty levels. Users can select **Easy, Medium, or Hard** difficulty, choose a practice duration from **30 seconds to 5 minutes**, and select different word-count options for each round.

### Key Features

* Upload and practice from **PDF, PNG, JPG, WEBP, and TXT** files.
* Paste custom paragraphs, questions, articles, or study material.
* AI-powered text extraction from supported PDFs and images.
* Select individual passages or practice multiple passages sequentially.
* Multiple typing modes including:

  * Raw text
  * Words only
  * Words + numbers
  * Words + punctuation
  * Words + numbers + punctuation
  * Commas & periods focus
* Timed sessions ranging from **30 seconds to 5 minutes**.
* Quick Practice with **Easy, Medium, and Hard** difficulty levels.
* Real-time **WPM, accuracy, words, and error tracking**.
* Character-level highlighting showing correct and incorrect typing.
* Automatic passage progression during practice.
* Detailed results after each session.
* Mistake analysis showing characters that were missed most frequently.
* Responsive interface designed for desktop and mobile screens.

### Technologies Used

**HTML5, CSS3, JavaScript, SVG, Google Fonts, and the Anthropic API** for AI-assisted text extraction from uploaded documents and images.

### Project Objective

The main objective of Typecraft is to provide a flexible typing-practice environment where users can train with their **own educational or professional material** instead of relying only on predefined typing exercises. The application combines customizable practice modes, timed sessions, real-time performance tracking, and error analysis into a single lightweight web application.
